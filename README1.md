Movies API

Краткое описание проекта
Асинхронный REST API для управления каталогом фильмов. Проект позволяет создавать, просматривать, редактировать и удалять информацию о фильмах, а также получать списки с пагинацией и фильтрацией. Написан на современном веб-фреймворке FastAPI с использованием асинхронной SQLAlchemy.

Основные возможности приложения
 Полноценный CRUD (создание, чтение, обновление, удаление) для фильмов.
 Валидация входящих данных с помощью Pydantic-схем.
 Пагинация списка фильмов (параметры `limit` и `offset`).
 Асинхронная работа с базой данных SQLite через драйвер `aiosqlite`.
 Автоматическая генерация интерактивной документации Swagger UI.
 Управление схемой базы данных через миграции Alembic.

Технологический стек
 **Язык программирования:** Python 
 **Веб-фреймворк:** FastAPI
 **ASGI-сервер:** Uvicorn
 **ORM:** SQLAlchemy  
 **База данных:** SQLite
 **Миграции:** Alembic
 **Валидация данных:** Pydantic

Основные эндпоинты
 GET / - Проверка статуса API.
 GET /movies/ - Получить список всех фильмов (с поддержкой пагинации, фильтрации и сортировки).
 GET /movies/{movie_id} - Получить информацию о конкретном фильме по ID.
 POST /movies/ - Добавить новый фильм в каталог.
 PUT /movies/{movie_id} - Полностью обновить информацию о фильме.
 PATCH /movies/{movie_id} - Частично обновить информацию о фильме.
 DELETE /movies/{movie_id} - Удалить фильм из каталога.

Фильтрация и сортировка
 limit - Количество записей для вывода.
 offset - Смещение для пагинации.
 year_min - Минимальный год выпуска.
 year_max - Максимальный год выпуска.
 min_rating - Минимальный рейтинг фильма.
 order_by - Поле для сортировки.

Модель данных
 id (int, primary key, index) - Уникальный идентификатор фильма.
 title (String, index, not null) - Название фильма.
 genre (String, not null) - Жанр фильма.
 rating (Float, not null) - Рейтинг фильма.
 year (Integer, not null) - Год выпуска фильма.

Ограничения базы данных
 check_movie_rating_range - Рейтинг фильма должен находиться в диапазоне от 0 до 10.
 check_movie_year_1888 - Год выпуска фильма должен быть не ранее 1888 года.
